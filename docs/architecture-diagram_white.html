Orchestrator Commands

All commands run from the project root with virtual environment activated

🔵 HiveQL Conversion
Convert HiveQL files to Spark SQL with accuracy dashboard
python -m orchestrator.orchestrator_agent --intent hive_only
Input: input/hive/*.hql
Output: output/hive/spark_sql/*.sql
Report: output/hive/accuracy/dashboard.html
🟣 Impala Conversion
Convert Impala SQL files to Spark SQL
python -m orchestrator.orchestrator_agent --intent impala_only
Input: input/impala/*.sql
Output: output/impala/spark_sql/*.sql
🧪 HiveQL Equivalence Testing
Run Hive vs Spark equivalence testing with MINUS validation
python -m orchestrator.orchestrator_agent --intent test_only
Source: input/hive/*.hql
Target: output/hive/spark_sql/*.sql
Containers: Hive 4.0 + Spark 3.5 (Finch)
🟢 MWAA Conversion
Convert Control-M XML or Airflow DAGs to MWAA
python -m orchestrator.orchestrator_agent --intent mwaa_only
Input: input/mwaa/control_m/*.xml
Output: output/mwaa/dags/*.py
🔄 Full Pipeline
HiveQL conversion + MWAA conversion in one run
python -m orchestrator.orchestrator_agent --intent full_pipeline
Phase 1: HiveQL → Spark SQL (all files)
Phase 2: Control-M → MWAA DAGs

Key Capabilities

Fidelity-Focused Conversion

Designed to preserve source logic, transformations and columns. Each conversion is checked by validation, accuracy scoring and equivalence testing, and should be reviewed before use.

HiveQL + Impala

Parallel Processing

Multiple files processed simultaneously with async concurrency. Large files chunked automatically.

3-5 concurrent

Self-Correction Loop

Automatic error detection and fix (max 3 attempts). Triggers on low accuracy or validation failure.

Autonomous

MINUS Equivalence Check

Equivalence Testing

Separate Reports

HiveQL and Impala get isolated accuracy dashboards. Test reports are per-query with detailed analysis.
